## Brand & Style

This design system establishes an approachable, warm, and distinctly delightful aesthetic for modern technical tools. It bridges high-utility developer instrumentation with the tactile charm, optimism, and warmth usually reserved for top-tier consumer apps. The target audience encompasses modern product engineers, technical founders, and creative technologists who spend long hours inside interfaces and crave an environment that feels humane, inviting, and uncluttered.

The visual direction rejects both sterile, monolithic dark-mode tooling and corporate, clinical enterprise palettes. Instead, it balances tactile softness with meticulous typographic rigor:
- **Clean Organic Canvas**: An airy, warm off-white foundation that eliminates eye fatigue and sets a sunny, welcoming atmosphere.
- **Micro-Delight & Kinetic Tactility**: Squishy pill controls, bouncy tactile feedback on press states, and contextual pastel badges that transform complex configurations into friendly, modular interactions.
- **Calibrated Vibrancy**: High-energy teal and sun-kissed coral paired with gentle, sunny pastels to make monitoring, debugging, and collaboration feel effortlessly light and rewarding.

## Colors

The palette is engineered around an organic, warm off-white canvas paired with energetic semantic accents. High-contrast, warm slate neutrals prevent the design from feeling childish while preserving legibility and accessibility.

### Canvas & Surfaces
- **App Background**: `#F7F7F5` — Warm alabaster paper base; softens high-frequency screen glare.
- **Surface Container (Base Card)**: `#FFFFFF` — Pure white for elevated modules and active panels.
- **Surface Sunken / Code Blocks**: `#F0EFEA` — Slightly deeper natural tint for inset fields, secondary shelves, and code containers.
- **Surface Hover**: `#ECEBE5` — Interactive feedback tone for neutral list items and ghost triggers.

### Core Brand Accents
- **Primary (Vibrant Teal)**: `#14B8A6` — Primary interactive focus, main action buttons, successful deployment states, and active tabs.
- **Primary Dim / Surface**: `#CCFBF1` — Minty soft container fill for teal chips and badges.
- **Secondary (Warm Coral)**: `#FF6B6B` — Urgent alerts, deletion actions, hot tags, and playful focal callouts.
- **Secondary Surface**: `#FFE4E6` — Tinted blush container for warnings and coral-accented chips.

### Contextual & Delight Accents
- **Sunny Pastel Yellow**: `#FEF08A` (Border / Accent: `#EAB308`) — Active highlights, warnings, and system notices.
- **Soft Sky Blue**: `#BAE6FD` (Border / Accent: `#0284C7`) — Informational indicators, documentation callouts, and secondary metrics.
- **Fresh Mint**: `#A7F3D0` (Border / Accent: `#059669`) — Positive delta indicators, operational health, and verification markers.

### Neutrals & Text Tones
- **Text Primary**: `#292524` — Deep stone charcoal; high contrast without harshness.
- **Text Secondary**: `#78716C` — Medium stone gray for helper text, meta counters, and secondary navigation.
- **Text Muted / Placeholder**: `#A8A29E` — Low-contrast stone for disabled states and empty input placeholders.
- **Subtle Border / Divider**: `#E7E5E4` — Warm hair-line borders for crisp containment against off-white backdrops.

## Typography

The typographic system pairs the welcoming, humanist curves of Plus Jakarta Sans with the technical authority of JetBrains Mono. This creates an immediate cognitive balance: structural text feels soft and expressive, while code, variables, and data payloads remain razor-sharp and utilitarian.

- **Headlines & Display**: Set in Plus Jakarta Sans with tight negative tracking and bold weights (`700`–`800`) to anchor dashboard overviews with clarity and friendliness.
- **Body & Editorial**: Neutral `400` weights provide effortless readability against the warm off-white canvas, keeping line-height generous to maintain an open, uncrowded feel.
- **Technical & Metadata**: Set in JetBrains Mono (`code-md` and `code-sm`) for terminal output, API endpoints, tokens, and numeric metrics, reinforcing developer-grade confidence inside a playful container.

## Layout & Spacing

The layout is built on a proportional 8pt base grid system that emphasizes airiness, breathing room, and soft containment.

### Responsive Breakpoints & Grid Structure
- **Desktop (1200px+)**: 12-column fluid grid, `margin-desktop` (48px), `gutter-desktop` (32px). Maximum content containment width is capped at 1440px to retain intimacy on wide displays.
- **Tablet (768px – 1199px)**: 8-column responsive grid, `margin-tablet` (32px), `gutter-tablet` (24px). Sidebar navigations collapse into floating icon ribbons or drawer panels.
- **Mobile (< 768px)**: 4-column dynamic grid, `margin-mobile` (16px), `gutter-mobile` (16px). Cards span the full column breadth; multi-step toolbars stack into sticky bottom navigation bars.

### Rhythm & Density
Whitespace inside this design system serves as an interactive cue. Tight gaps (`space-xs` to `space-sm`) connect tightly coupled controls (such as pill button icon-label pairs), while generous layout gaps (`space-2xl` to `space-4xl`) separate independent operational clusters.

## Elevation & Depth

Visual hierarchy uses warm, diffuse ambient drop shadows paired with soft, low-contrast borders. Hard black drop shadows are strictly prohibited; all shadows are warm-tinted using the neutral stone tone (`#292524`) to blend naturally with the `#F7F7F5` ground plane.

- **Flat / Ground (`elevation-0`)**: Directly on canvas (`#F7F7F5`). Used for outer viewports, inactive tabs, and segmented control backgrounds.
- **Card Tier (`elevation-1`)**: Background `#FFFFFF`, border `1px solid #E7E5E4`, shadow `0 2px 8px -2px rgba(41, 37, 36, 0.04), 0 1px 4px -1px rgba(41, 37, 36, 0.02)`. Used for standard content modules and metric panels.
- **Interactive / Hover Tier (`elevation-2`)**: Background `#FFFFFF`, border `1px solid #D6D3D1`, shadow `0 8px 16px -4px rgba(41, 37, 36, 0.08), 0 2px 6px -1px rgba(41, 37, 36, 0.04)`. Accompanied by a subtle `-1px` transform on hover to produce a physical, springy interaction.
- **Floating Overlays & Popovers (`elevation-3`)**: Background `#FFFFFF`, border `1px solid #E7E5E4`, shadow `0 16px 32px -8px rgba(41, 37, 36, 0.12), 0 4px 12px -2px rgba(41, 37, 36, 0.04)`. Used for tooltips, dropdown menus, modals, and command bars (`Cmd + K`).

## Shapes

The design system embraces high-roundedness (`roundedness: 3`) to deliver its friendly, tactile, and approachable consumer aesthetic. Rounded geometries humanize technical controls, making dense logic configurations feel modular and inviting.

### Geometry Hierarchy
- **Pill Elements (`9999px`)**: Interactive buttons, filter pills, status badges, search triggers, and active notification chips.
- **Cards & Surfaces (`16px` to `20px`)**: Dashboard containers, metric widgets, and configuration cards. `18px` is standard desktop; `16px` is mobile.
- **Inputs & Field Controls (`10px` to `12px`)**: Text fields, search bars, dropdown selectors, and code parameter cells.
- **Micro Elements (`6px` to `8px`)**: Checkboxes, code tag pills, and nested popover sub-menus.

## Components

### Buttons
- **Primary Pill**: Full `9999px` border radius, `#14B8A6` background, `#FFFFFF` text (`label-md`). Hover shifts to `#0D9488` with an ambient glow shadow (`0 4px 12px rgba(20, 184, 166, 0.3)`). Active state applies a tactile scale compression of `scale(0.97)`.
- **Secondary Pill**: Off-white fill `#FFFFFF`, border `1px solid #E7E5E4`, `#292524` text. Hover changes surface to `#F0EFEA`.
- **Destructive / Accent Action**: `#FF6B6B` pill with white text for critical deployments, deletions, or high-priority warnings.
- **Ghost / Icon Pill**: Transparent ground, `#78716C` icon, fills with `#ECEBE5` on hover.

### Chips & Badges
- **Status Pills**: Height `24px` or `28px`, pill radius, `code-sm` or `label-sm` weights.
  - *Healthy / Live*: `#CCFBF1` background, `#0F766E` text, featuring a pulsing 6px `#14B8A6` dot.
  - *Warning / Building*: `#FEF08A` background, `#854D0E` text.
  - *Error / Alert*: `#FFE4E6` background, `#BE123C` text.
  - *Info / Staging*: `#BAE6FD` background, `#0369A1` text.
- **Filter Chips**: Neutral rounded capsules (`rounded-full`), padded `space-xs` vertically by `space-md` horizontally, with subtle hover feedback and an active teal highlight.

### Inputs & Form Controls
- **Text Inputs**: Height `44px`, `10px` to `12px` border radius. Solid `#FFFFFF` background, border `1px solid #E7E5E4`. Focused state uses a crisp `2px solid #14B8A6` ring with `2px` offset. Placeholder text in `#A8A29E`.
- **Code Inputs / Key Fields**: Styled with `#F0EFEA` fill, `10px` radius, and JetBrains Mono (`code-md`) typography for clear distinction from natural-language inputs.

### Checkboxes & Radio Buttons
- **Checkboxes**: `20px x 20px`, `6px` radius. Neutral state has `#E7E5E4` border and `#FFFFFF` fill. Checked state pops to `#14B8A6` with a white check icon and animated bouncy expansion.
- **Radio Buttons**: `20px x 20px`, fully circular. Selected state features a `#14B8A6` outer boundary encasing an 8px solid teal concentric core.

### Cards & Module Containers
- **Standard Card**: Radius `18px`, `#FFFFFF` surface, `1px solid #E7E5E4` border, `elevation-1` shadow. Inner padding defaults to `space-xl` (24px).
- **Interactive Action Card**: Contains a responsive hover transition (`elevation-2`, subtle border tint `#D6D3D1`, `-1px` vertical lift).

### Lists & Activity Feeds
- **Feed Items**: Borderless items stacked on `#FFFFFF` cards, separated by `1px solid #F0EFEA`.
- **Row Hover**: Rounded `10px` micro-highlight using `#F7F7F5` with `transition: background 150ms ease`.

### Developer Tooling Additions
- **Inline Snippet Box**: Sunken container (`#F0EFEA`), `12px` radius, JetBrains Mono font, equipped with a right-aligned pill-shaped "Copy" button.
- **Command Palette (`Cmd + K`)**: Floating modal (`elevation-3`), `20px` radius, deep `#FFFFFF` ground with subtle backdrop blur (`backdrop-filter: blur(8px)`) on the underlying view.
